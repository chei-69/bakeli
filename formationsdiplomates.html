Informatique de Gestion

Durée : 24 mois, avec un stage pédagogique garanti de 3 mois chaque année. Diplôme : Technicien Supérieur.

Vous allez apprendre à :

  • Automatiser des processus
  • Structurer et analyser des données
  • Modéliser une base de données
  • Piloter l'activité d'une entreprise
  • Travailler à plusieurs dans un projet

Vous allez utiliser :

  • Excel et Google Sheets
  • Access, MySQL et PostgreSQL
  • Power BI
  • Python pour l'automatisation

Vous pouvez devenir :

  • Technicien en informatique de gestion
  • Analyste de données junior
  • Assistant de direction numérique
